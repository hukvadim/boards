# Мої дошки

Trello-подібна дошка з `TASKS.md` усіх проєктів у `C:\Projects`.

- `node build.mjs` — зібрати `boards.json` з `C:\Projects\*\TASKS.md`
- відкрити `index.html` через будь-який статичний сервер (або GitHub Pages)
- `?b=<папка>` — відкрити конкретну дошку; остання відкрита запамʼятовується

Формат TASKS.md: `# Назва`, колонки `## В роботі / Далі / Баги / Ідеї / Готово`,
картки `- [ ] що (файли) — зупинився: де` (`- [x]` — зроблено).

- `node sync.mjs` — зібрати і викласти на GitHub (кінець дня)
